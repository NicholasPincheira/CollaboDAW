# Collaboration UX Checklist

## Track controls

- [ ] Mute is local-only.
- [ ] Solo is local-only.
- [ ] Record Arm is local recording state.
- [ ] Monitor controls local audibility.
- [ ] Transmit controls publication to peers.
- [ ] Receive/Subscribe controls remote media delivery.
- [ ] Volume/Pan are local monitor controls.

## Session

- [ ] Each participant sees their own mix state.
- [ ] Participants see who is transmitting what.
- [ ] Latency shows local and remote metrics separately.
- [ ] `est.` marks estimates.
- [ ] Resync does not rewrite recordings.
- [ ] Click is local.

## Safety/quality

- [ ] No hidden audio routing.
- [ ] No browser timer as musical clock.
- [ ] No WebSocket audio transport.
- [ ] No mandatory AI processing.
